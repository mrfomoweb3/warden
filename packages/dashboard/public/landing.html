The problem

Your agents can spend. Nobody is watching.

AI agents now pay for APIs, data and services on their own through x402. Most of them pay from a hot key with no spending controls at all.

…the same API, 30 times in 10 minutes. No one was asked.
01

Hot keys, no limits

A funded agent can pay anyone, any amount, any number of times. There is no daily cap and no pause button.

02

Loops burn money quietly

One retry bug can pay the same API dozens of times in minutes. You find out from the balance, not from an alert.

03

Alerts can't stop a payment

Monitoring tells you after the money has moved, and the Sui RPC gateway keeps only about three days of history.

The solution

A watchdog that learns your rules, then gets out of your way

Warden sits between your agents and their money. It learns what normal looks like for each one, acts on-chain the moment something isn't, and asks you only when your rules say to.

Tell it once, in plain English
  • Block anything over $20/daycap, enforced on-chain
  • Ask me before any new counterpartyescalate
  • Freeze an agent that pays the same API 50× in an hourpause

Rules are stored as data in Walrus Memory. When Warden asks you something, your reply becomes a new rule, so it doesn't ask twice.

How it works

Watch every payment, act in seconds, remember everything

  1. ObserveNew vault payments, from the Tatum Sui RPC
  2. RecallThe agent's normal, its rules, past incidents
  3. AssessCaps, velocity, new or lookalike payees
  4. DecideAllow, tighten, pause or ask you
  5. ActOn-chain, through SpendVault
  6. LearnYour reply becomes a rule in Walrus
The tech

Built on Sui, Tatum and Walrus Memory

Every part has one job. The chain feed is live, the memory is permanent, and the brakes are a Move contract only you and Warden can touch.

Tatum Sui RPC

The live feed

One suix_queryEvents call per cycle covers every agent, because they all spend through one vault. Polls every 15s after activity, backing off to 120s when quiet.

Walrus Memory

The long-term record

Rules, incidents, your replies and each agent's normal spend. The gateway forgets after about three days; Walrus keeps everything, and Claude Code can read it over MCP.

SpendVault

The brakes, in Move

Holds each agent's allowance and enforces per-payment and daily caps. Warden can pause an agent or tighten its caps; only you can withdraw.

x402 on Sui

How agents pay

Agents pay for APIs per request, settled on Sui. Warden pays for its own risk check before it trusts a counterparty it hasn't seen.

Agent loop

The brain, in TypeScript

A LangGraph loop where every payment decision is deterministic: caps, velocity, new or lookalike addresses. A Groq-hosted model only turns your plain-English messages into rules.

Telegram

Where it talks to you

Set rules in plain English, answer the odd question, and get a daily digest. There are no confirm buttons between steps.

Memory, not logs

Every decision leaves a record you can read

Each memory is a small JSON record on Walrus. Warden recalls them before every decision, and you can open the same memory from Claude Code to ask why it did something.

{
  "type": "rule",
  "text": "Ask me before any new counterparty over $5",
